# CryptoAPIMax

CryptoAPIMax enables high-performance, distributed processing of cryptocurrency market data through a scalable gateway service.

CryptoAPIMax is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoAPIMax.git`
2. `cd CryptoAPIMax`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
